----------------------------------------------------------------
AUTH FLOW
----------------------------------------------------------------

1. User visit "/" (homepage)
   → Middleware check session
   → No session? Redirect to /auth/login

2. User click "Log Masuk dengan Google"
   → Google OAuth
   → Callback to /auth/callback

3. Auth Callback check profile
   → Profile incomplete? Redirect to /profile
   → Profile complete? Redirect to /

4. Profile Page
   → User fill: name, phone, address
   → Save to database
   → Redirect to /

5. Homepage
   → Show menu
   → Header: [Profile] [Logout]

6. User click Profile
   → Go to /profile
   → Pre-filled with current data from DB

7. User click Logout
   → Supabase sign out
   → Redirect to /auth/login

----------------------------------------------------------------
PROFILE REQUIREMENTS
----------------------------------------------------------------

Mandatory fields (ALL USERS):
  1. name (TEXT) - Not empty
  2. phone_number (TEXT) - Malaysian format
  3. address (TEXT) - Not empty

Phone validation:
  Regex: /^(\+?6?01)[0-46-9]-*[0-9]{7,8}$/
  Valid: 0123456789, +60123456789
